# Specification conflicts and open decisions

Source of truth: *OSRIP Academic Booklet (English), design-stage edition*. The items
below are places where the booklet is internally inconsistent, is silent on something
code has to decide, or where the build brief and the booklet differ. Each item records
the interim decision taken in code so it can be reviewed, not silently inherited.

Status key: **Open** = needs a supervisor or team decision; **Interim** = a reversible
default is implemented and flagged.
