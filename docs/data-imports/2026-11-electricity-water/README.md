## Evidence classes

| Class | Meaning | Where it is kept |
|---|---|---|
| observed | A published statistic for a past period | Observations (import workflow) |
| provisional | A published statistic the source marks provisional (2025) | Observations, revision status `provisional` |
| estimate | An approximate figure the source gives ("around 9%") | Outlook items |
| forecast | A projection (peak demand to 2032) | Outlook items |
| policy_target | A national target (30% renewable by 2030), not an achievement | Outlook items |
| planned | A plant or project in procurement or construction | Outlook items |
| under_consideration | An option being studied (Sohar 2032) | Outlook items |

Outlook items never enter the observation tables. The database refuses an observed or estimated outlook item dated in or after the statement's year (2026), so every 2032 figure is a forecast, target, plan or option.

## Staging

Migration 0036 (the utility scope and indicators, and the outlook table) must be applied first. Then, from the repository folder: `backend/.venv/Scripts/python.exe backend/scripts/stage_electricity_water.py docs/data-imports/2026-11-electricity-water/OSRIP_Electricity_Water_2022_2032_Source_Verified.xlsx --stage --as USERNAME`. A data manager then approves and publishes the imports in Data Management, and approves the outlook items; `--reject` withdraws what is not yet published or approved.
